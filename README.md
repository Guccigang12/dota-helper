# Dota Companion

Внешний компаньон для Dota 2 (External Companion Tool):

1. **Аналитика матча** — ростер 10 игроков с разделением на Radiant/Dire,
   оценка стоимости Steam-инвентаря через **Lolzteam Market API**.
2. **Экранный переводчик чата** — захват области чата, OCR
   (PaddleOCR / Tesseract), машинный перевод на русский, история,
   прозрачный HUD поверх игры, уведомления.
3. **Саундпад** — плавающий Always-on-Top виджет с аудио-триггерами,
   воспроизведение в выбранное устройство (Virtual Audio Cable).

Стек: **Python 3.10+ · PyQt6 · asyncio (aiohttp) · mss · sounddevice**.

---

## Безопасность (VAC)

Архитектура намеренно **не взаимодействует с процессом игры**:

- **Данные матча** — официальный *Game State Integration* (Valve, тот же
  механизм, что у Overwolf) + чтение файла `console.log` (запуск Dota 2
  с параметром `-condebug`). Никакого чтения памяти, инжекта, DLL или хуков.
- **OCR** — снимок области экрана (как OBS/Discord).
- **Саундпад** — обычный вывод звука в аудиоустройство Windows.
- **Хоткеи** — пассивные `RegisterHotKey` Win32.

Честная оговорка: абсолютную гарантию «VAC никогда не сработает» не даст
никто, но данный класс инструментов (GSI + скриншот + файл лога) не даёт
Valve повода для детекта и легален — он не читает память и не модифицирует
игру. Не добавляй в проект модули чтения памяти или инжекта.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

### OCR (выбери один вариант)

**Вариант A — PaddleOCR** (лучший для китайского/английского/испанского):
```bash
pip install paddlepaddle paddleocr
```

**Вариант B — Tesseract** (fallback): установи
[Tesseract 5](https://github.com/UB-Mannheim/tesseract/wiki) и языки
`chi_sim`, `eng`, `spa`, затем:
```bash
pip install pytesseract
```
Приложение автоматически переключится на Tesseract, если PaddleOCR не
установлен.

## Настройка Dota 2

1. **GSI**: скопируй `config/gamestate_integration_dota_companion.cfg` в
   ```
   <Steam>/steamapps/common/dota 2 beta/game/dota/cfg/gamestate_integration/
   ```
   и перезапусти Dota 2.

2. **console.log**: в Steam → Dota 2 → Свойства → Параметры запуска добавь:
   ```
   -condebug
   ```
   (нужен для лога чата; ростер матча приходит из OpenDota по match_id).

3. **Режим окна**: для OCR переведи игру в **«Окно без рамок»**
   (Borderless Windowed) — полноэкранный режим скрывает сцену от захвата.

4. **API-токен Lolzteam Market**: возьми на
   [lzt.market/account/api](https://lzt.market/account/api) и вставь в
   поле настроек (или в файл `%APPDATA%/DotaCompanion/settings.json`,
   ключ `market_token`).

## Запуск

```bash
python main.py
```

Хоткеи:

| Клавиша | Действие |
|---|---|
| `Ctrl + Shift + F8` | выбор области чата |
| `F9` | пауза / возобновление OCR |
| `F10` | выход из приложения |

### Работа с модулями

- **Матч**: ростер всех 10 игроков (Steam ID, ники, герои, команды)
  приходит из GSI **в реальном времени** (`player.team2/team3`) — оценки
  считаются прямо во время игры. Steam ID появляются с фазы
  Strategy Time (в рейтинговых матчах до неё профили скрыты).
  После конца матча ростер дополнительно уточняется из OpenDota по
  `match_id`. **Оценка инвентаря автоматическая**: у каждого игрока
  известен Steam ID, и стоимость всего его Steam-инвентаря берётся
  напрямую из Steam-профиля через `GET /steam-value?link=…`. Включи
  «Авто-оценку» — все 10 игроков оценятся сами.
- **Чат**: выбери область чата, включи OCR. Распознанный текст
  переводится (Google бесплатно / **Gemini API** / DeepL / LibreTranslate)
  и попадает в историю, HUD поверх игры и уведомления. Для Gemini
  укажи API-ключ (aistudio.google.com/apikey) и модель — по умолчанию
  `gemini-3.5-flash-lite` (самая быстрая, ~0.5–0.8 с на сообщение).
  Слайдеры *Text size* и *Showtime* управляют HUD.
- **Саундпад**: положи звуки в папку `%LOCALAPPDATA%/DotaCompanion/sounds`
  (wav/mp3/ogg/flac); файл `<label>.wav` подхватится к триггеру с тем же
  именем. В «Устройство вывода» выбери виртуальный кабель
  (VB-Audio Virtual Cable) — звуки пойдут «в микрофон».

## Структура проекта и взаимодействие компонентов

Проект разделен на логические модули. Центральным узлом, связывающим все компоненты воедино, является `app.py`.

### 1. Ядро и Оркестрация
- **`main.py`** — Точка входа в приложение. Инициализирует PyQt6-приложение и запускает фоновый поток с циклом событий `asyncio` для асинхронных задач, после чего передает управление классу `DotaCompanionApplication`.
- **`dota_companion/app.py`** — Главный оркестратор. Хранит ссылки на все менеджеры (UI, GSI, OCR, Soundpad). Принимает сигналы от дочерних компонентов (например, пришел новый ростер из GSI) и решает, что с этим делать (обновить `match_state`, запустить оценку инвентаря, обновить UI).
- **`core/async_worker.py`** — Мост между синхронным миром интерфейса (PyQt) и асинхронным миром сетевых запросов (asyncio). Позволяет безопасно запускать фоновые HTTP-запросы, не замораживая интерфейс.
- **`core/settings.py`** — Менеджер настроек. Читает и сохраняет конфигурацию пользователя (токены, выбранные языки, регионы OCR) в JSON-файл в папке `%APPDATA%`.

### 2. Модуль интеграции с Dota 2 (`dota_companion/dota/`)
- **`gsi_server.py`** — Локальный веб-сервер (aiohttp), который слушает порт 4000. Сама Dota 2 автоматически отправляет сюда JSON-данные о текущем матче каждые полсекунды. Парсит этот JSON и извлекает список 10 игроков (включая Steam ID из поля `allplayers` для Турбо-режима).
- **`match_state.py`** — Хранилище состояния текущего матча. Содержит структуру `Player` и логику слияния (`merge_group`) нового ростера от GSI со старым, чтобы не терять уже загруженные инвентари при каждом тике игры.
- **`console_log.py`** — В реальном времени читает (tail) файл `console.log` Доты. Ищет там сообщения из чата (для передачи в переводчик) и строчки со Steam ID (как резервный способ привязки игроков, если GSI не отдал их).
- **`steam_api.py`** и **`opendota.py`** — Клиенты для работы с внешними API. Если у игрока скрыт Steam ID в клиенте игры, эти файлы используются для поиска его ID по нику через Steam Community и базу OpenDota.

### 3. Модуль оценки инвентарей (`dota_companion/market/`)
- **`client.py`** — Клиент для работы с Lolzteam Market API. Делает асинхронные HTTP-запросы (`/steam-value`) для оценки стоимости инвентаря. Содержит логику обработки ошибок, лимитов (Rate Limit) и автоматических повторов (ретраев).
- **`models.py`** — Структуры данных (например, `InventoryValue`) для удобного форматирования полученных валют и чисел.

### 4. Экранный переводчик (OCR) (`dota_companion/ocr/`)
- **`capturer.py`** — Делает скриншоты заданного участка экрана (где находится чат Доты) с помощью библиотеки `mss` с частотой 1-2 кадра в секунду.
- **`engine.py`** — Движок распознавания текста (PaddleOCR или Tesseract). Работает в отдельном процессе/потоке, чтобы не тормозить UI. Принимает картинки от `capturer`, находит на них текст и отдает дальше.
- **`translator.py`** — Отправляет распознанный текст в выбранный ИИ-переводчик (Gemini, Google, DeepL) и возвращает готовый русский текст.

### 5. Модуль Саундпада (`dota_companion/soundpad/`)
- **`audio.py`** — Отвечает за непосредственное воспроизведение аудиофайлов. Использует библиотеку `sounddevice` для вывода звука в указанное аудиоустройство (например, виртуальный кабель для трансляции в микрофон).
- **`triggers.py`** — Сканирует папку со звуками и связывает их с горячими клавишами. Следит за нажатиями хоткеев и отдает команду в `audio.py`.

### 6. Графический интерфейс (`dota_companion/ui/`)
- Отвечает только за отрисовку и взаимодействие с пользователем. Никакой сложной бизнес-логики здесь нет, при нажатии на кнопки отправляются сигналы (Signals) в `app.py`.
- **`main_window.py`** — Главное окно программы с вкладками.
- **`match_tab.py`** — Вкладка матча. Отрисовывает две таблицы (Силы Света и Силы Тьмы), иконки героев, ники и стоимость инвентарей.
- **`chat_overlay.py`** — Прозрачное "Always on Top" некликабельное окно, которое накладывается поверх Доты и показывает переведенный текст чата.
- **`crop_overlay.py`** — Затемненный оверлей для выделения области экрана мышкой (как в инструментах скриншотов), чтобы указать приложению, где находится чат.

### Как они взаимодействуют (Пример: Авто-оценка игроков)
1. Начинается матч. **Dota 2** отправляет HTTP POST запрос в **`gsi_server.py`**.
2. **`gsi_server.py`** парсит JSON, находит 10 игроков и кричит наверх (через сигнал): *"Новый ростер!"*
3. **`app.py`** ловит сигнал, берет этот ростер и передает его в **`match_state.py`** для обновления таблицы.
4. Затем **`app.py`** видит, что у новых игроков еще не оценен инвентарь. Он вызывает функцию оценки.
5. Запрос уходит в **`market/client.py`**, который стучится в Lolzteam API.
6. Когда API возвращает стоимость инвентаря ($500), **`app.py`** записывает эту сумму в игрока и дергает **`match_tab.py`** с командой *"Отрисуй изменения"*.
7. Пользователь видит результат на экране.


## Сборка в .exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name DotaCompanion ^
  --collect-all paddleocr main.py
```
(без PaddleOCR `--collect-all paddleocr` можно убрать).

## Известные ограничения

- OCR требует **Borderless Windowed**; эксклюзивный fullscreen не
  захватывается (как и в OBS).
- Оценка по Steam-ссылке работает только для профилей с **публичным**
  инвентарём: если инвентарь скрыт, API вернёт ошибку «Инвентарь скрыт».
  Ники из невидимых символов (zero-width) отображаются как «Player …».
- В рейтинговых матчах GSI скрывает Steam ID/ники игроков до фазы
  Strategy Time — до этого момента панели могут быть пустыми, оценки
  появятся, как только матч начнётся.
- OpenDota публикует матч только после его окончания (и с задержкой на
  парсинг) — как запасной источник после конца игры.
